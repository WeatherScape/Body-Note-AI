# BodyNote AI

腹筋を割るまで、毎日1分で記録できるボディメイクコーチです。

食事、体重、筋トレを細かく管理したいけれど入力が面倒で続かない人向けに、ワンタップ記録とルールベースのコーチングを組み合わせたMVPとして実装しています。バックエンド、認証、外部AI APIは使わず、すべてブラウザのlocalStorageに保存します。

## セットアップ

```bash
npm.cmd install
npm.cmd run dev
```

PowerShell の実行ポリシーで `npm` が止まる環境では、`npm.cmd` を使ってください。

## 主な機能

- 初回オンボーディングで目的、体重、身長、年齢、性別、運動頻度、管理スタイルを入力し、推定消費カロリー・目標カロリー・目標タンパク質を自動計算
- 毎日の習慣がかわいい相棒に反映される「Body Buddy」をダッシュボード最上部に表示
- 「相棒をつくる」Creatorで、ベースタイプ・耳・毛色・表情・首輪・チャームカラー・名前をカスタマイズ
- Fat Burn、Muscle、Recovery、Consistency の4ゲージと7日間の傾向で、数字だけではない変化を可視化
- 今日のボディメイクスコア、摂取カロリー、タンパク質、PFC、筋トレ、体重をまとめたダッシュボード
- 鶏むね肉、白米、卵、プロテインなどのワンタップ食品追加
- 手入力した食品を「マイ定番」として保存し、次回から自分専用のワンタップ食品として追加
- 自分用プリセットは既存プリセットと同じカードUIで追加でき、編集・削除にも対応
- 食品検索、追加時の通知/効果音に対応
- 初回設定後にクイック記録へ誘導し、まず1品追加するミッションを表示
- 食事タイミング別の記録、手入力、食事テンプレート、今日の食事からテンプレート保存・編集・削除
- 筋トレ種目プリセット、前回重量表示、合計セット数表示
- 自分用の筋トレ種目を追加・削除し、固定プリセットにないメニューも記録
- 体重・体脂肪率ログ、目標ライン付き推移グラフ、7日平均体重、過去の日別サマリー
- 目標進捗、開始からの体重変化、連続記録、タンパク質達成日、筋トレ日数をまとめた「変化が見えるカード」
- 週間レビューで記録日数、平均スコア、筋トレセット、平均タンパク質を確認
- スコア・栄養・筋トレをまとめたSNS共有向けの成果カード
- CanvasでSNS共有向けPNG画像を生成し、対応端末ではWeb Shareから共有
- 食事、体重、筋トレを合わせて判断するルールベースAIコーチ
- PWA対応により、スマホのホーム画面へ追加してアプリのように起動
- Android/Chrome向けのホーム画面追加プロンプト、iPhone/Safari向けの追加案内を表示
- 端末保存・外部AI API未使用・医療/栄養指導ではない旨の安心表示
- 右上の設定ボタンから、目標・体情報・運動頻度をいつでも再入力
- GoogleフォームURL差し替え式のフィードバック導線、データ出力、データリセットに対応
- 画面更新後もlocalStorageから復元

## 既存アプリより優れている点

1. 入力の最短距離を優先しています。クイック記録は食事に集中し、食品プリセットと食事テンプレートをワンタップで追加できます。
2. ユーザーごとの生活に合わせて育ちます。よく食べる食品をマイ定番に保存できるため、使うほど入力が短くなります。
3. 数字だけで終わりません。Body Twin、ボディメイクスコア、「今日やること3つ」で、ユーザーが次に何をすればいいかをすぐ判断できます。
4. 食事と筋トレを分断しません。筋トレしたのにタンパク質が少ない日など、体づくりに必要な文脈を合わせて優しくアドバイスします。

## 実装メモ

- コーチ文は `lib/coach.ts` の純粋関数で生成しています。現在は外部AI APIを使っていないため、利用ごとのAPIコストは発生しません。将来OpenAI APIに置き換える場合も、画面側のデータ構造を大きく変えずに差し替えられます。
- スコア計算は `lib/summary.ts` に分離しています。初心者でも継続しやすいよう、記録が少なくても厳しすぎない配点にしています。
- 目標カロリーとタンパク質の初期値は `lib/nutrition.ts` で計算しています。医療・栄養指導ではなく、個人開発MVPとしての目安です。
- Body Buddy の状態計算は `lib/bodyTwin/calculateBodyTwinState.ts` に分離し、UIは `components/body-twin/` に分割しています。
- Body Buddy の外観は `bodynote:bodyTwinAppearance` としてlocalStorageに保存し、あとから編集できます。
- UIはNext.js App Router、TypeScript、Tailwind CSS、shadcn/ui風のローカルコンポーネントで構成しています。
